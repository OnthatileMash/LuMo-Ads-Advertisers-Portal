# LuMo Ads Advertiser Portal — Front-End Prototype

Pages: login, dashboard, campaigns, campaign builder, creatives, audience, reports, billing, settings.

The prototype reuses the supplied LuMo logo from the existing Captive Portal package and defines all brand colors as CSS custom properties.

This is a front-end implementation only. Authentication, APIs, persistence, real uploads, billing and authorization must be connected before production.
